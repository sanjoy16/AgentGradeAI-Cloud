# Faculty review and report update

Based on the supplied report(2).pdf, the default presentation now prioritizes the approved score, rubric, code locations, reasons for lost/held marks, actionable revision guidance and all recorded agent outcomes. The report retains actual scope/status and does not copy the sample's unsupported confidence or blanket correctness claims.

Faculty review shows a compact agent table. Full tool inputs, steps, logs and numbered source remain in collapsed sections. The checked-scope explanation is also collapsed. Approval, password authentication, score moderation rules and data storage are unchanged.

PDF layout is content-driven rather than padded to ten pages. It contains score/rubric, feedback, every agent's status and recorded result, proposed tests, linked notes when present and source identity. It summarizes long fields explicitly as excerpts. Full source and raw evidence are retained in the application. The legacy detailed renderer remains in the package but is no longer the default export.

To run: open Docker Desktop, enter this extracted project folder in Terminal, and run `bash run-mac.command`. Open the URL it prints. Stop the prior app with Control+C before restarting. Use the password entered at the new launch. Existing approved submissions can be downloaded using the new presentation; scores and stored findings are preserved and tools are not rerun. To obtain new analysis outcomes, submit a new assessment.
